Section 3: Introduction to MySQL
*********************************

branch: section3-intro-to-mysql

A Database is a set of related data and how it is organized
DBMS: Database Management Systems

Transactions & ACID (easy with one user, becomes very complex with many transacting users)

- Atomicity: All statements must be able to complete
- Consistency: Changes do not violate constraints
- Isolation: Reads inside the transaction see changed data.
             Reads outside transaction see original data (until commit).
- Durability: Once committed, changes are permanent.

There are some techniques to prevent Lost Updates:

- Pessimistic Locking: uses a database lock to prevent inflight transactions and will allow transactions to complete
- Optimistic Locking

DDL: Data definition language
DML: Data manipulation language


Administration best practices
- Use a schema for your application
- don't use a "superuser" acc for your application user
- apply the principle of minimal authorities
- Account used by application often called a "service account"
- Service account should only have CRUD access
- Service account should not be able to perform DDL operations
    - Prevents malicious acts via SQL Injections attacks

- review docs about data types in mysql and hibernate
